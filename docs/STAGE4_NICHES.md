# Stage 4: выбор продукта — анализ с пруфами (раунд 17)

Метод: каждой гипотезе — проверка по источникам (Bing-выдача, официальные
страницы). Вердикт по каждой нише пишется по найденным игрокам, а не по ощущениям.
Если игроки есть и берут деньги — ниша плотная; если игроки есть и бесплатные —
спрос есть, монетизация под вопросом; если игроков нет — либо окно, либо его нет.

## Платёжный рельс: вердикт

- **Международные (Stripe/Gumroad/Ko-fi/Oracle)** — заблокированы для РФ
  (требуют международную карту). Подтверждено опытом пользователя.
- **Boosty** — выплаты деградировали: в выдаче массово «БУСТИ НЕ ВЫВОДИТ
  ДЕНЬГИ», «Boosty предупредила о трудностях с выводом» (frankmedia),
  треды по обходным путям с комиссией 11,7% (quasa.io). **Не рельс.**
- **Telegram Stars → TON → P2P-рубли** — рабочий сквозной путь:
  Fragment.com жив (проверено напрямую: маркетплейс Stars/Gifts/Premium/Ads,
  вывод в TON), гайдов по выводу Stars→TON через Fragment от разных
  источников 2025–2026 (autogram, vc.ru, гайды). TON→рубли — через P2P-биржи
  (bybit p2p и аналоги), платёж приходит на карту РФ. **Это основной рельс.**
- **Self-custody USDT (TRC-20)** — приём без KYC, для крипто-нативных
  плательщиков. Дополнительный рельс.

## 5 кандидатов под платный TG-продукт (в порядке привлекательности)

1. **«Регуляторный патруль» для одной лицензируемой вертикали**
   (общепит / медицина / салоны красоты / стройка):
   ежедневный дайджест изменений НПА, новых форм отчётности,
   сроков. Данные — публичные (pravo.gov.ru, ленты Гарант/Консультант,
   региональные порталы).
   Платящие аналоги дорогие, бесплатных узко-профильных нет.
   **Наш движок (sentinel/phosphor pipeline) уже умеет такую работу.**
2. **Тендерный срез для микро-бизнеса**: только 44-ФЗ, одна область,
   сумма до ~300к, узкий ОКПД — «одна ниша, а не все тендеры».
   Игроки широки, узкий срез почти не покрыт; покупатель — микро-фирма.
3. **Алерты грантов/поддержки для НКО и стартапов**: новые конкурсы,
   дедлайны, требования — подписка в ₽/мес. Спрос реален,
   монетизируемых узких игроков мало.
4. **CVE/ИБ-алерты на русском для DevOps и small SecOps**: наши
   security-колонии уже собирают CVE/advisories; платные аналоги
   западные (на рубли не купят), русского узкого SMS/TG-продукта мало.
5. **Мониторинг брендов/товарных знаков и доменов для маркетологов**:
   появление похожих ТЗ, drop-доменов, новых конкурентов в каталогах.
   Западные аналоги; в РФ пробел.

Все пять строятся **поверх существующего роя** — любая переиспользует
механику «собери бесплатные источники → очисти → доставь в TG», которую рой
уже делает для сайтов (data pipeline + cron — готовы, нужен только TG-бот как
новый renderer вместо sitegen).

## Честная оценка

Чудесной пустой ниши нет — шесть проверок показали плотность везде, где
деньги водятся. Наше реальное преимущество — нулевая себестоимость сбора:
бота можно сделать за дни и держать бесплатно, а конкурентам с ручным
копированием так нельзя. Первый рубль — ₽-микроподписки (Stars/ЮMoney),
через недели при минимальном продвижении в тематических чатах.
Zero-Human-Touch — у сборки и доставки, не у продаж. Это надо проговорить
вслух: **чудесного авто-дохода в этой нише нет**, есть дешёвая доставка
живого спроса.

## Требуется одно решение

Выбор одной вертикали из 5 (или своей). После выбора: три шага —
(1) TG-бот = новый renderer роя, (2) платный доступ через Stars/ЮMoney,
(3) два-три канала посева в TG. Рельс (Stars→TON→P2P) готов к проверке
пользователем в @fragment.
