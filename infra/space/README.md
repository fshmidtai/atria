# Atria Console — пульс улья

Статический дашборд автономной мультиагентной системы **Atria**: карточки
колоний (сайты, QA, дата-продукты), бюджет, агенты. Данные тянет из
публичного датасета состояния `fshmidtai/atria-hive-state`, куда их
автоматически публикует `genesis.py` после каждого цикла.

Рой: https://github.com/fshmidtai/atria
